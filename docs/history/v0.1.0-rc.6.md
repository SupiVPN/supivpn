# SupiVPN v0.1.0-rc.6

This release candidate reorganizes the Go project and introduces release bundle
format 2. Update package consumers before upgrading from an earlier candidate.

## Changes

- Use a single Go module at the repository root, commands under `cmd/`,
  implementation packages under `internal/`, and shared fixtures under `testdata/`.
- Keep documentation in `docs/`, example configuration in `examples/`, local
  build outputs in `local/`, and packaged releases in `out/dist/`.
- Update Make targets, CI checks, artifact validation and GoLand configurations
  for the new source layout.
- Decouple archive paths from source paths: executables are in `bin/`, the
  Lambda ZIP in `lambda/`, SQL files in `migrations/`, and `release.json`
  at the archive root.

## Compatibility

- **Breaking packaging change:** `bundle.json.format` is now 2. Consumers must
  explicitly support this format; the downloader rejects format 1. Published
  older packages are unchanged and must not be repacked.
- Archive filenames keep their existing format.
- Runtime configuration, command arguments and the Lambda ZIP members
  `bootstrap` and `client.ovpn.template` are unchanged.
- Database schema remains 8, with compatibility for schemas 7 and 8. SQL migration
  contents are unchanged; the directory reorganization requires no new migration.
- Retain a reviewed recovery path when changing package consumers: the new
  validator cannot load an older format-1 package for rollback.

This is a prerelease intended for validation before a stable release.

- Target: `linux-amd64`
