# SupiVPN v0.1.1

Changes since [v0.1.0](v0.1.0.md).

## Changes

- Update OpenVPN to 2\.7\.8 and pin refreshed CI toolchains
- Refresh Go dependencies and PostgreSQL test images for v0\.1\.1

## Compatibility

These notes summarize commit subjects; they do not assert runtime or migration compatibility. Review configuration and migration changes before upgrading. The Release page reports schema compatibility from the verified package manifests.

## Package compatibility

- Targets: `linux-arm64` (primary), `linux-amd64`
- Bundle format: `3`
- Database schema: `9`; compatible VM schemas: 7, 8, 9
- Public, agent and recovery Lambdas require schema `9`, separate roles and a controlled cutover from the combined Lambda.
